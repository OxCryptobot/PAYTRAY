# Verified Paytray Product Framing

**Source:** `https://github.com/OxCryptobot/PAYTRAY` and the user-provided `README.md`  
**Verified:** 2026-08-14

Paytray is a Phase 1 skeleton for an **AI platform that combines expert discovery, real-time communication, and blockchain payments**. Its intended value is to connect freelancer-client engagement with time-based payment streams, allowing parties to fund time rather than rely solely on lump-sum service payments.

The product model centers on three connected capabilities:

1. **Expert discovery** identifies and ranks relevant service providers.
2. **Real-time communication** moves a selected match into an active, contextual engagement.
3. **Blockchain payments** provide ERC-20 payment streams with start, stop, participant access, and withdrawal concepts.

The confirmed repository baseline is commit `ae7c6c6` on `master`. The repository is intentionally a minimal backend-first foundation: `MasterBlueprint.md` provides a target architecture/roadmap, `packages/backend` contains the runtime skeleton, and root scripts address the backend workspace.

The prior “meme crypto token generation SaaS” framing was incorrect and must not be used in subsequent Paytray documentation, skill instructions, designs, or implementation decisions.
